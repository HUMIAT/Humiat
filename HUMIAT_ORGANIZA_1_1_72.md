# HUMIAT Organiza 1.1.72

## Cadastro de Itens no padrão planilha

- Cadastro de Itens redesenhado para o mesmo padrão visual do Estoque.
- Uma linha compacta por item, em ordem alfabética.
- Cabeçalho fixo e colunas alinhadas para custo, preço, status e ações.
- Atalhos para Estoque, Contagem e Compras no topo.
- Busca simplificada por Item ou Categoria.
- Código do item removido da interface, da busca e dos formulários.
- Novos itens deixam de criar código operacional sem necessidade.
- Edição de itens não depende mais do campo código.

Versão: 1.1.72
