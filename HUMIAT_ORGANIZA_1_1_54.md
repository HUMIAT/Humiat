# HUMIAT Organiza 1.1.54

## Atualizações — links padrão e base 2021.0

- 2021.0 passa a ser tratada exclusivamente como versão-base e não aparece na lista de links de pacotes.
- A primeira atualização com link continua sendo 2021.1.
- Cria automaticamente os três links padrão globais da atualização:
  - Banco de Dados
  - Atualiza pendrive
  - Pendrive Cliente
- Cada link padrão pode ser ativado ou inativado individualmente.
- O administrador pode incluir novos links padrão quando necessário.
- Links padrão ativos são liberados no Google Drive para o Gmail do cliente e enviados junto com os pacotes comprados no fluxo de atualização em casa.
- Link padrão ativo sem URL impede o envio e informa claramente qual arquivo precisa ser configurado.
